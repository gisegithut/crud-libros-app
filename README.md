📌 Introducción al proyecto

Este proyecto es una aplicación CRUD (Crear, Leer, Actualizar y Eliminar) desarrollada en Python. Permite gestionar una lista de libros de forma sencilla, almacenando información como el título, autor y otros datos básicos.

El objetivo del proyecto es practicar la manipulación de datos y la lógica de programación en Python, aplicando operaciones fundamentales de gestión de información.

🛠️ Tecnologías utilizadas
Python 🐍
Git & GitHub
VS Code
(Opcional: SQLite / archivos JSON / CSV, si lo usas)
⚙️ Instalación y configuración

Clona el repositorio:

git clone https://github.com/gisegithut/crud-libros-app.git

Accede al proyecto:

cd crud-libros-app

Crea entorno virtual (opcional pero recomendado):

python -m venv venv

Actívalo:

Windows:
venv\Scripts\activate

Instala dependencias (si tienes requirements.txt):

pip install -r requirements.txt
▶️ Ejecución del proyecto

Ejecuta el programa principal:

python main.py
